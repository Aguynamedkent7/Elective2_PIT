# Decisions and deviations from PLAN.md

| Date | # | Decision | Why |
|---|---|---|---|
| 2026-10-28 | D4 | **Hand-written recursive-descent parser** (`domain/.../parser/ExprParser.kt`, port of `compileExpr`) instead of exp4j. `ExpressionEngine` interface kept. | The golden parser cases need behaviour exp4j doesn't have: `Unexpected character "$"`, `Missing ")"`, `Expression ends early`, function application without parentheses (`√x`), `x e` → `Unknown symbol "xe"`, and the exact unary-minus/`^` precedence. Porting was ~150 lines with no dependency; all 25 parser cases pass. |
| 2026-10-28 | — | Version catalog pinned to latest stable on 2026-10-28: AGP 9.4.1, Kotlin 2.4.21, KSP 2.3.12, Gradle 9.8.2, Compose BOM 2026.09.00, Hilt 2.60.1, Navigation 2.10.2, Lifecycle 2.11.0, compile/target SDK 37. | PLAN §0 rule. AGP 9 has built-in Kotlin, so Android modules don't apply `kotlin-android`. |
| 2026-10-28 | — | `:domain` adds `Max iterations must be at most 10000` (not in math.js). | PLAN §8 cap. Golden cases unaffected. |
| 2026-10-28 | — | Root solver errors raised mid-run are `RootFailure(message, rows)`, so the UI can keep rows computed before the error. | PLAN §8 ("rows computed so far remain visible"); math.js only returns the message. |
| 2026-10-28 | — | Logo updated to the second handoff (S-curve through the root dot, from `docs/assets/logo-sketch.png`). | Owner's logo change; only `docs/assets`, `PLAN.md` §2/§7.2, prototype and screenshots differ between handoffs. `golden.json` identical. |
| 2026-10-28 | — | Fonts bundled as Google Fonts variable TTFs: Geist, Geist Mono, Bricolage Grotesque (`ui/src/main/res/font`). | D5; families taken from the `.cD` scope in `template3.html`. |
| 2026-10-28 | D3 | **Custom Compose `Canvas` plot** (`ui/chart/`) instead of MPAndroidChart + overlay. | The plan's own fallback. MPAndroidChart is unmaintained and JitPack-only, and every NumLab-specific element (markers, bands, tangents, draggable line, draw-on) would live in an overlay that must track the chart's transform. The prototype's `chart2.jsx` ported directly; one coordinate mapper means overlays can't misalign. Sampling runs synchronously on pan/zoom (≤ 600 evals, sub-millisecond) rather than on `Dispatchers.Default`. |
| 2026-10-28 | — | **Graph canvas is an overlay of the `home` destination**, not its own NavHost route. History is a NavHost route. | The circular reveal must show Home underneath while it grows; NavHost transitions can't clip one destination over another. Open/closed state lives in the ViewModel + `SavedStateHandle`, so rotation and process death keep it. |
| 2026-10-28 | — | Home and canvas share one `WorkbenchViewModel` (activity-scoped). | PLAN §6.3: the canvas Inputs tab is bound to the same state as Home. |
| 2026-10-28 | — | Bottom sheet uses `Animatable` + `draggable` with three snaps instead of `AnchoredDraggable`. | Same behaviour (peek 218 dp / 56 % / 90 %, fling), fewer moving API parts. |
| 2026-10-28 | — | History dedupe matches **any** entry with identical inputs (bumps its `updatedAt`), not only the newest. | Prototype behaviour; reopening an old run and graphing it again shouldn't create a copy. |
| 2026-10-28 | — | Seeds follow PLAN §5.1 (Newton `eˣ − 3x`), not the prototype (`cos x − x`). | The plan names the seeds explicitly. |
| 2026-10-28 | — | "Try other method" previews the result inline on the card; **Open** adopts the previewed inputs. | PLAN §6.4 wording; the prototype inserted a new history entry instead. |
| 2026-10-28 | — | `kotlinx-serialization` annotations on `:domain` input models; `:domain` also depends on coroutines (Flow in repository interfaces). | Both are pure Kotlin. Lets history JSON, SavedStateHandle and drafts share one versioned codec (`RunCodec`). |
| 2026-10-28 | — | Parser whitespace regex spells out JS `\s` instead of `(?U)\s`. | Android's ICU regex rejects `(?U)`; this crashed on device but not on the JVM. Found on the emulator. |
| 2026-10-28 | — | Interpolation P(x) does not morph for 180 ms when a node's y changes; badge count does not pop. | Small polish items from §7.4/prototype CSS left out; dragging is immediate as specified. |
| 2026-10-28 | — | No Macrobenchmark module / screenshot tests (Paparazzi/Roborazzi). | Optional in the plan. Cold start measured with `am start -W` on an API 35 emulator instead (429–510 ms warm, 791 ms first launch after install). Visual review was done by screenshots against `docs/ui/*.png`. |
| 2026-10-28 | — | Not tested: physical device, tablet/foldable emulator, API 26/30, TalkBack walkthrough, RTL pseudo-locale. | Only a Pixel 6 API 35 emulator was available. Layout uses start/end and `supportsRtl`; all icon buttons have content descriptions. |
